# 🚀 Primeira Vaga em TI — Assistente NotebookLM

Um NotebookLM do Google treinado com fontes selecionadas (artigos, vídeos, guias e materiais próprios) para ajudar iniciantes a conquistarem sua **primeira vaga em Tecnologia da Informação**. O assistente analisa currículos, tira dúvidas sobre carreira e orienta os primeiros passos de quem está entrando na área.

## 📌 Sobre o projeto

Conseguir a primeira oportunidade em T.I. costuma ser um dos maiores desafios de quem está migrando de carreira ou começando do zero. Este projeto reúne, em um único NotebookLM, conteúdos confiáveis sobre:

- Como estruturar e revisar um currículo de T.I.
- Como se preparar para processos seletivos e entrevistas técnicas
- Dicas práticas de quem já passou por esse processo

O NotebookLM foi alimentado com **diversas fontes de texto e vídeo** selecionadas manualmente, permitindo que as respostas sejam sempre baseadas em conteúdo confiável e citável.

## 🎯 O que o assistente faz

- ✅ Analisa e sugere melhorias no seu currículo
- ✅ Responde dúvidas sobre como começar na área de T.I.
- ✅ Ajuda a se preparar para entrevistas
- ✅ Resume e cita trechos das fontes usadas, evitando "alucinações"

## 🛠️ Como usar

1. Acesse o link do notebook compartilhado acima.
2. Faça login com sua conta Google.
3. Envie seu currículo (PDF/Docs) na aba "Fontes".
4. Faça perguntas como:
   - *"Analise meu currículo e aponte pontos de melhoria"*
   - *"Monte um roteiro de estudos de 3 meses para minha primeira vaga em dev"*
  
## 💡 Como criar seu próprio NotebookLM parecido

1. Acesse [notebooklm.google.com](https://notebooklm.google.com/)
2. Crie um novo notebook
3. Adicione fontes (PDFs, links, vídeos do YouTube, textos colados)
4. Use o botão **Compartilhar** para gerar um link público
5. Cole o link neste README
